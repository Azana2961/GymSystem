# GymSystem

A modern, full-stack Gym Management System application designed for member tracking, attendance check-ins, automated WhatsApp alerts, and administrative management.

## Project Structure

- `backend/`: Node.js & Express server with SQLite, QR attendance verification, and automated WhatsApp notifications.
- `frontend/`: Flutter web & desktop management dashboard application.
  - Features: Dashboard, Members, Trainers, Analytics, Settings.
  - Built with Flutter 3.x, Material Design 3, Provider.
- `tablet/`: Web-based kiosk attendance check-in interface.
- `tablet_app/`: Flutter mobile & tablet kiosk client for biometric/QR member check-ins.
